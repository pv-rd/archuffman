# Реализация алгоритма Хаффмана
## Семестровый проект по практике программирования на C++

> В данном проекте реализован алгоритм сжатия Хаффмана, в том числе программа-кодер и программа-декодер. Реализация алгоритма включает также несколько библиотек, которые тоже могут быть полезны для работы с файлами и данными. 

> Помимо реализации алгоритма проект включает анализ его эффективности с помощью программы-генератора случайного набора байтов с заданным распределением.
# Структура проекта

1. Библиотека ByteTable

Реализует функции работы с таблицей подсчёта количества бит (таблица частот). По умолчанию таблица имеет размер 512, тип данных ```std::uint32_t``` с целью поддержки хранения в этой же таблице частот промежуточных узлов дерева Хаффмана. Основные реализованные функции:

``` std::uint32_t * get_table(const char * file_name, bool count_size = true)``` - получает имя файла, возвращает таблицу частот, по умолчанию записывает в ячейку с индексом 256 размер файла в байтах.

``` std::uint32_t * get_size(const char * file_name)``` - получает имя файла, возвращает размер в байтах.

``` int count_nonzero(std::uint32_t * table)``` - принимает указатель на первый элемент таблицы, возвращает число ненулевых элементов.

```void print_table(std::uint32_t * table, PrintMode mode)``` - выводит таблицу в консоль в формате Байт\tКоличество, доступны режимы Full (по умолчанию) - вся таблица, Half - первая половина (собственно частоты байт), Nonzero - ненулевые строки (из всех).
