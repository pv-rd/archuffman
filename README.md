# Реализация алгоритма Хаффмана
## Семестровый проект по практике программирования на C++

> В данном проекте реализован алгоритм сжатия Хаффмана, в том числе программа-кодер и программа-декодер. Реализация алгоритма включает также несколько библиотек, которые тоже могут быть полезны для работы с файлами и данными. 

> Помимо реализации алгоритма проект включает анализ его эффективности с помощью программы-генератора случайного набора байтов с заданным распределением.
# Структура проекта

1. Библиотека ByteTable

Реализует функции работы с таблицей подсчёта количества бит (таблица частот). По умолчанию таблица имеет размер 512, тип данных uint32_t с целью поддержки хранения в этой же таблице частот промежуточных узлов дерева Хаффмана. Основные реализованные функции:

``` uint32_t * get_table(const char *)``` - получает имя файла, возвращает таблицу частот
